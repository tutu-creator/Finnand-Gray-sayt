# Finn and Gray – Services Page Recreation

A recreation of the "Creative Services" page of the Finn and Gray website, built with React and Tailwind CSS for practice.

**Live demo:** https://tutu-creator.github.io/Finnand-Gray-sayt/

![Finn and Gray screenshot](public/screenshot.png)

## Features
- Fully responsive design for mobile, tablet and desktop
- Component-based structure with reusable React components
- Client-side routing with React Router
- "Schedule intro call" booking integrated with Calendly
- Icons with React Icons

## Built With
- React 19
- Vite
- Tailwind CSS
- React Router
- React Calendly
- React Icons
- ESLint
